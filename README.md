# Écaille Scintillante

A Discord community bot (Python, discord.py) built for "Écaille Scintillante," a private Sea of Thieves-themed community.

## Features

- **Reaction-based role assignment**: members react to a themed onboarding message to self-assign a pirate-flavored role (Pirate, Matelot, Chercheur d'or, Aventurier, etc.), with a DM confirmation on join and leave.
- **Event rally system** (`+creatEvent`): posts a live-updating announcement where members react to join as Captain or Member, or opt out; the embed reflects the current roster in real time.
- **Owner-only setup commands** (`+roleSetup`, `+welcomeSetup`): post the onboarding and welcome messages with the community's lore-driven copy.
- **`+info`**: bot lore/credits card.

## Stack

Python, discord.py

## Status

Personal community project, no longer actively maintained.
